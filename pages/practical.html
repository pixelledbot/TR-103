Applied learning guide

Practical Learning

A guided view of practical topics that connect the programme's core concepts with common technical workflows.

Learning through application

From Concepts to Practical Experience

Practical learning supports understanding by connecting key ideas with activities, tools and workflows. The following topics outline areas for exploration during the four-week training programme.

01Linux Command-Line Exercises

Develop familiarity with the Linux terminal and common commands.

Activities
  • Navigate directories and inspect files.
  • Practise file and directory operations.
  • Review permissions and basic system commands.
Focus: command-line navigation, file handling and essential Linux operations.

02Cloud Computing Exercises

Explore how cloud services provide computing, storage and networking resources.

Activities
  • Identify IaaS, PaaS and SaaS examples.
  • Compare cloud deployment models.
  • Review virtual machines, storage and networking.
Focus: understanding cloud service choices and infrastructure building blocks.

03Git and Version Control

Understand the workflow used to track source-code changes and collaborate.

Activities
  • Create or inspect a repository.
  • Review staging and commit concepts.
  • Explore branches, merges and remote repositories.
Focus: a clear version-control workflow from repository to shared code.

04Docker and Containerisation

Explore how Docker packages software and its dependencies into containers.

Activities
  • Review images and containers.
  • Study common Docker commands.
  • Understand the purpose of Dockerfiles.
Focus: container concepts and repeatable application environments.

05Application Deployment

Connect development concepts with the process of making an application available.

Activities
  • Review the stages of a basic deployment workflow.
  • Identify application, environment and configuration needs.
  • Relate containers to deployment fundamentals.
Focus: understanding the path from an application package to a deployment environment.
Key takeaway

Building Technical Confidence

Working through Linux, cloud, Git, Docker and deployment concepts builds a connected foundation for understanding modern software development and infrastructure workflows.
