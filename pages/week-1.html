DAILY TRAINING RECORD

Learning Journal

The first week introduced the basic technologies and concepts required for working with cloud infrastructure. The sessions covered cloud computing, DevOps, Linux, shell scripting, networking and virtual machines.

01 DAY ONE

INTRODUCTION

Introduction to Cloud Computing and DevOps

The first session introduced the concepts of Cloud Computing and DevOps. Cloud computing provides computing resources such as servers, storage, databases and networking over the internet instead of requiring organisations to maintain all infrastructure locally.

DevOps was introduced as a combination of development and operations practices that improves collaboration, automation and the software delivery process.

TOPICS COVERED
  • Meaning of cloud computing
  • Benefits of cloud infrastructure
  • Introduction to DevOps
  • Development and operations workflow
KEY LEARNING

Understood how cloud computing provides flexible infrastructure and how DevOps helps automate and improve software development and deployment.

Daily Reflection

This session provided an overview of the training programme and established the connection between cloud infrastructure and DevOps practices.

02 DAY TWO

LINUX FUNDAMENTALS

Introduction to Linux and Its File System

The second session focused on Linux as an operating system widely used in servers, cloud platforms and development environments. Its command-line interface allows users to interact with the system through commands.

The Linux file system was explored, including important directories such as root, home, etc, var and bin. Basic navigation and file handling operations were introduced.

COMMANDS PRACTISED 
pwd
ls
ls -la
cd Documents
mkdir project
touch file.txt
cp file.txt backup.txt
mv file.txt newfile.txt
rm newfile.txt
TOPICS COVERED
  • Linux operating system
  • Linux directory structure
  • File and directory navigation
  • Creating and managing files
KEY LEARNING

Learned how to navigate the Linux file system and perform common file and directory operations through the terminal.

Daily Reflection

Practising Linux commands helped develop familiarity with terminal-based system interaction and file management.

03 DAY THREE

SYSTEM ADMINISTRATION

Linux Users, Permissions and Shell Scripting

This session covered Linux user management and file permissions. Linux uses user and group-based permissions to control who can read, write or execute files and directories.

The permission categories were studied along with basic commands for viewing and changing permissions. The session also introduced shell scripting, which allows repetitive terminal tasks to be automated.

COMMANDS PRACTISED 
whoami
id
who
groups
ls -l
chmod 755 script.sh
chown user file.txt

Basic Shell Script

A simple shell script was studied to understand how multiple commands can be executed together. 

#!/bin/bash

echo "Welcome to Linux"
echo "Current user:"
whoami

echo "Current directory:"
pwd

The script can be saved as script.sh and executed after granting the required permission. 

chmod +x script.sh
./script.sh
TOPICS COVERED
  • Linux users and groups
  • Read, write and execute permissions
  • chmod and chown
  • Shell scripting basics
  • Basic automation
KEY LEARNING

Understood how Linux controls file access and how shell scripts can automate simple administrative tasks.

Daily Reflection

The practical examples demonstrated how permissions support system security and how scripts reduce repetitive manual work.

04 DAY FOUR

NETWORKING FUNDAMENTALS

Networking Basics and Communication Protocols

The fourth session introduced networking concepts that are essential for understanding communication between computers and cloud servers.

Topics included IP addresses, DNS, network ports and the HTTP and HTTPS protocols. An IP address identifies a device on a network, while DNS translates domain names into IP addresses.

CONCEPTS COVERED
  • IP addresses
  • Public and private IP addresses
  • Domain Name System (DNS)
  • Network ports
  • HTTP and HTTPS
IMPORTANT PORTS
  • HTTP — 80
  • HTTPS — 443
  • SSH — 22
  • DNS — 53

Network Commands

Common networking commands were introduced to check connectivity, inspect network information and communicate with web servers. 

ping google.com
netstat -tuln
curl https://example.com

The netstat command may require the appropriate networking utilities to be installed on some Linux distributions.

Daily Reflection

Learned how devices communicate over networks and how basic commands help troubleshoot connectivity and inspect network services.

05 DAY FIVE

VIRTUALISATION PRACTICAL

Introduction to Virtualisation and Ubuntu VM Setup

The final session of the week introduced virtualisation, a technology that allows multiple virtual machines to run on a physical computer.

A virtual machine operates like an independent computer with its own operating system, virtual processor, memory and storage. Virtualisation is widely used in cloud infrastructure because it allows physical hardware resources to be shared efficiently.

CONCEPTS COVERED
  • Virtualisation
  • Hypervisors
  • Virtual machines
  • VM resources
  • Ubuntu Linux
PRACTICAL TASK

Set up an Ubuntu virtual machine by selecting system resources, attaching the operating system image and completing the installation.

VM Setup Process

  1. Install a virtualisation application.
  2. Download the Ubuntu ISO image.
  3. Create a new virtual machine.
  4. Allocate memory, processor and storage.
  5. Attach the Ubuntu ISO file.
  6. Complete the Ubuntu installation.
  7. Start the virtual machine and open its terminal.
Daily Reflection

The practical activity connected the theoretical concept of virtualisation with the actual setup of a Linux-based virtual machine.

SKILLS DEVELOPED

  • Navigate the Linux file system using terminal commands.
  • Manage Linux users, groups and file permissions.
  • Write and execute basic shell scripts.
  • Understand IP addresses, DNS, ports and HTTP/HTTPS.
  • Use ping, netstat and curl for basic network operations.
  • Understand virtualisation and set up an Ubuntu virtual machine.
